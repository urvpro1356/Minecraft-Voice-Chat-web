# Minecraft Community Hub & Voice Chat

A modern, high-contrast dark theme community platform for Minecraft players, builders, and competitive teams. Features Minecraft Java & Bedrock account linking, active voice chat channels, server browser, squad matchmaking, community discussions, and direct messaging.

## Features

- **Minecraft Account Linking**:
  - Verification for Java Edition and Bedrock / MCPE accounts
  - Gamertag validation, in-game command code simulation (`/link MC-****`), and verified badges
- **Voice Chat & Communication**:
  - Docked floating voice bar with live microphone mute, audio deafen, and disconnect controls
  - Animated speaking activity indicators and ping indicators
  - Direct messaging and squad voice call integration
- **Server IP Browser & Ping**:
  - Real-time status indicators, active player count progress meters, and ping latency metrics
  - 1-click IP copy with instant toast confirmation
  - Custom server addition modal
- **Squad Groups & Parties**:
  - Filterable by game mode (Bedwars, Survival, Skyblock, Netherite PvP)
  - Member rosters with player avatars, tags, and party chat
- **Community Discussions**:
  - Category filtering (Builds, Redstone, Guides, Survival, PvP)
  - Trending, Newest, and Most Popular sorting
  - Voting, nested replies, bookmarking, and discussion publishing
- **Topic Panel & Contests**:
  - Live statistics (builders count, weekly projects, growth percentage)
  - Official build battle contests with countdowns and coin prizes
  - Top contributor leaderboards

## Tech Stack

- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Vite**

## Getting Started

### Prerequisites

- Node.js 18+ or Bun

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

The application will be accessible at `http://localhost:3000`.

### Production Build

```bash
npm run build
```
